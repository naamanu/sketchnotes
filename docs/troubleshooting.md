## Build

### `SDK location not found. Define a valid SDK location with an ANDROID_HOME environment variable or by setting the sdk.dir path in your project's local properties file`
Create `android/local.properties`:
```bash
echo "sdk.dir=$HOME/Android/Sdk" > android/local.properties
```
Or `export ANDROID_HOME=$HOME/Android/Sdk`.

### `Failed to install the following Android SDK packages as some licences have not been accepted`
```bash
yes | ~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=$HOME/Android/Sdk --licenses
```

### `Unsupported class file major version` / Gradle complains about Java
Use **JDK 21**. Check with `java -version`. If several JDKs are installed, point Gradle at the right one: `export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64`.

### `Warning: SDK processing. This version only understands SDK XML versions up to 3…`
Harmless. The command-line tools are newer than the bundled Android Gradle Plugin's parser.

### `error: cannot find symbol … RecognitionCandidate`
Import it from `com.google.mlkit.vision.digitalink.common.RecognitionCandidate`, not `…recognition.RecognitionCandidate`.

### `TS2882: Cannot find module or type declarations for side-effect import of '*.css'`
`src/env.d.ts` must contain `declare module "*.css";`.

### Text renders in a fallback font / fonts missing
`public/fonts` is generated by `postinstall`. Run `npm install` again (or `npm run postinstall`), then rebuild.

### The first build is very slow
The first run downloads Gradle 8.14 (about 200 MB), Maven dependencies, and possibly extra build-tools. Later builds take about 15–30 s.

### I ran `npx cap add android` and native features broke
That regenerates `android/` from a template, which drops `InkPlugin.java`, the `MainActivity` registration and the ML Kit dependency. Restore it with `git checkout -- android` (and remove untracked template files with `git clean -fd android` if needed). Use `npx cap sync android`, never `cap add`, on this repo.

## Install / adb

### `adb: command not found`
Use the full path, `~/Android/Sdk/platform-tools/adb`, or add `platform-tools` to `PATH` (see [development.md](development.md#android-sdk-command-line-only)).

### adb doesn't see the tablet
1. Check that **USB debugging** is on (Developer options).
2. Use a **data** cable. Some cables only charge. `lsusb` should list the tablet.
3. Watch the tablet for the **"Allow USB debugging?"** prompt. It only appears while the tablet is unlocked.
4. Restart the server: `adb kill-server && adb devices`.
5. On Linux, if it shows `no permissions`, add a udev rule for the vendor (Lenovo is `17ef`):
   ```bash
   echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="17ef", MODE="0660", GROUP="plugdev"' \
     | sudo tee /etc/udev/rules.d/51-android.rules
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```
   Make sure your user is in `plugdev`.

### `device unauthorized`
Unlock the tablet and accept the prompt. If it never appears: **Developer options → Revoke USB debugging authorisations**, then unplug and replug.

### `INSTALL_FAILED_UPDATE_INCOMPATIBLE` (signatures do not match)
The installed app was signed with a different key (debug vs release, or a different machine's debug key). Export a backup in the app first, then:
```bash
adb uninstall dev.nana.sketchnotes   # ⚠ deletes the app's data
npm run install-tablet
```
and import the backup.

> Debug keys are per machine (`~/.android/debug.keystore`). To build from two computers without reinstalling, copy that keystore between them.

### `INSTALL_FAILED_INSUFFICIENT_STORAGE`
Free up space on the tablet. The APK is about 20 MB, plus about 20 MB for the handwriting model.

## Running the app

### Header hidden behind the status bar
The app relies on the `--safe-area-inset-*` variables injected by Capacitor 8's SystemBars plugin. If you've changed `capacitor.config.json`, make sure you haven't turned off its inset handling. Check the computed `--safe-area-inset-top` on `<html>` in Chrome DevTools.

### White screen on launch
Inspect with `chrome://inspect` and read the console. Common causes:
- `dist/` wasn't synced: run `npm run apk`, which builds and syncs.
- A runtime error after changing code: the console shows the stack.

### Finger draws instead of panning (or the pen does nothing special)
Excalidraw turns on **pen mode** the first time it sees stylus input. Toggle it from the canvas menu (☰, top-left). If your stylus reports itself as touch (some passive styluses do), pen mode and palm rejection can't work. You need an active pen that reports `pointerType: "pen"`.

### "Share PNG" or "Export backup" does nothing
These open the Android share sheet. Check the tablet: the sheet may be behind a notification shade. In logcat, look for `Capacitor/Plugin` errors from `Filesystem` or `Share`.

### Excalidraw's own "Export image" / "Save to…" menu is missing
That's intentional. Those use browser download APIs that Android WebView doesn't support. Use **Share PNG** and **⚙︎ → Export backup**.

## Handwriting recognition

### The ✍️→Aa toggle isn't shown
You're running in a browser (`npm run dev`). Recognition needs the native plugin, so use the APK.

### "Model download failed: …"
The first use needs internet to download the English model (about 20 MB). Connect to Wi-Fi and write again. The download retries automatically. Google Play services must be present and up to date. On devices without Play services (some custom ROMs), ML Kit model downloads fail.

### "Call prepare() first"
The plugin was called before the model was ready. This normally can't happen through `recognize()`, which prepares first. If you see it, check logcat for an earlier `prepare` failure.

### "Couldn't read that — left it as ink"
ML Kit returned no candidates for any line. Write larger and more clearly, keep the line level, and pause after each phrase. Make sure you used the **pencil** tool: only freedraw strokes are recognised.

### Converted text is wrong
Tap **undo** to get the ink back, then rewrite it, or double-tap the text and fix it by keyboard. Each phrase is recognised as a whole, so writing a full word or phrase in one go reads better than single letters.

### My sketches keep turning into text
Turn **✍️→Aa** off while sketching. Use **Aa Convert selection** for the writing you want converted.

### Text written in a box didn't become its label
The box needs to be a rectangle, ellipse or diamond, not rotated, and **without an existing label**. The **middle** of your writing must be inside the box.

## Data

### My diagrams disappeared after reinstalling
Uninstalling or clearing app storage deletes everything, and only a backup can bring it back. `npm run install-tablet` (`adb install -r`) does **not** delete data. See [data-and-backups.md](data-and-backups.md#what-deletes-your-data).

### Import says "Not a SketchNotes backup file"
The file must be JSON exported by **⚙︎ → Export backup** (`"version": 1` with an `index` key). `.excalidraw` files can't be imported directly yet.
